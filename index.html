Litestream Backup

A private, single-user backup tool that continuously replicates SQLite databases from its owner's server to the owner's own Google Drive using rclone and Litestream.

What it does

The tool runs on the owner's server and uploads encrypted, versioned backup files to the owner's own Google Drive. It is not a public service, is not distributed, and does not serve other users. Access is limited to the account owner.
