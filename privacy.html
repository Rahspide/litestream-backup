Privacy Policy

Litestream Backup · Last updated: October 6, 2026

This application ("the App") is a private, single-user backup tool operated by the owner of the Google account it is authorized with. The App uses the Google Drive API solely to store backup files created by the owner's server.

Data accessed

The App accesses only the files and folders it creates in the owner's own Google Drive. It does not read, collect, or process any other user data, and it does not access data from any other Google account.

How data is used

Backup data is uploaded to the owner's own Google Drive for personal archival purposes only. No data is sold, shared, transferred to third parties, or used for advertising. No humans read the data. The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data storage and retention

All backup data remains within the owner's Google Drive account and is retained according to the owner's own retention settings. OAuth credentials are stored locally on the owner's server.
